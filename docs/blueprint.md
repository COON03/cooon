# **App Name**: 7일의 상인: 무기 가게 생존기

## Core Features:

- 7일 제한 무기 가게 경영: 매일 무작위로 바뀌는 무기 재고와 손님 요청을 기반으로 7일 동안 무기 가게를 경영합니다. 목표 수익을 달성하지 못하면 게임 오버됩니다.
- 무기 조합 시스템: 기본 무기를 조합하여 더 희귀하거나 강력한 무기를 제작합니다. 조합 결과는 무작위로 생성됩니다.
- 손님과 거래 인터페이스: 손님의 요구 사항(공격력, 속도, 디자인 등)을 카드 형태로 표시하고, 사용자는 간단한 터치로 판매 및 가격 협상을 진행합니다.
- 자동 저장 + 파일 삭제 엔딩: 게임을 플레이하는 동안 자동으로 저장되며, 게임 종료 시 저장 파일이 삭제되어 매번 새로운 도전이 가능합니다.
- 배속 플레이 모드: 초보자용 20~30분 플레이를 기본으로, 빠른 플레이를 선호하는 사용자를 위해 10분 이내에 플레이할 수 있는 배속 모드를 제공합니다.
- SNS 공유 기능: 성공 또는 실패 시 최종 수익 그래프, 희귀 조합 성공 인증샷, 7일 도전 성공/실패 배지, 오늘의 거래 기록 이미지 등을 생성하여 소셜 미디어 공유를 지원합니다.

## Style Guidelines:

- 기본 색상: 가게와 무기의 분위기를 나타내는 짙은 갈색 (#4E342E)을 사용합니다.
- 배경 색상: 어두운 배경 위에 약간 더 밝은 회색빛 갈색 (#2E2926)을 적용합니다.
- 액센트 색상: 손님의 요청과 무기 정보를 강조하기 위해 황금색 (#B8860B)을 포인트 색상으로 사용합니다.
- 본문 및 제목 글꼴: 'Literata' (세리프) 글꼴을 사용하여 가독성을 높이고 전통적인 느낌을 강조합니다.
- 무기, 재료, 손님 유형을 나타내는 데 사용할 픽셀 스타일 아이콘을 사용합니다.
- 카드 레이아웃을 사용하여 무기, 손님 요청 및 거래 정보를 표시합니다.
- 거래 성공 또는 실패 시 부드러운 애니메이션 효과를 사용하여 피드백을 제공합니다.
